Questions

Do I need a database server?

No. Prism runs with an embedded database out of the box. Point it at PostgreSQL when you want a managed database or higher concurrency — backups move between the two.

What happens if our license expires?

You get a 14-day grace period, then Community limits apply. Nothing is deleted: dashboards stay readable and you can export everything.

Which files can Prism read?

Excel workbooks (.xlsx, .xlsm) and delimited text (CSV, TSV, semicolon- or pipe-separated) in UTF-8 or legacy encodings. Formulas are never executed — Prism reads the stored values.

Can people outside the company see dashboards?

Yes — create a public link with an optional expiry, or embed a chart in another site (Pro and Business). Links can be revoked at any time and every view is counted.

Is there an API?

A documented REST API with personal API keys lets you automate imports, refreshes and queries — for example a nightly upload from your ERP export.
